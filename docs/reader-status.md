## 使用与配置

换机/容器/CI 的必要配置、离线检查与风险判读见 [部署与风险说明](reader-operations.md)。

[独立运行](reader-standalone.md)、[全文规则](reader-fulltext.md)、[下载](reader-download.md)、
[调用预算](reader-pipeline.md)、[完整真实测试记录](reader-real-data-test.md)。

百炼可在**当前PowerShell进程**复用既有变量，不会写.env或系统变量：

```powershell
$env:OPENAI_API_KEY = $env:DASHSCOPE_API_KEY
$env:OPENAI_BASE_URL = $env:DASHSCOPE_BASE_URL
$env:LLM_MODEL = 'qwen3.7-plus'
$env:LLM_API = 'chat_completions'
$env:READER_USE_LLM = '1'
$env:READER_ENABLE_THINKING = '0'
```

READER_ENABLE_THINKING是可选的提供者扩展，只接受0/1且仅支持chat_completions；
不设置时不发送extra_body、不猜测提供者行为。仅在服务明确支持enable_thinking时配置。
本次定向全文配置为context_tokens=32768、output_tokens=8192，显式设置max_calls与
max_reserved_tokens；不同模型应重新确认。预算是本地准入预留，不是实际账单。
