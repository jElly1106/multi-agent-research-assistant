## 模型配置与真实请求

初始 Reader 配置有 OPENAI_API_KEY，但没有 LLM_MODEL/OPENAI_BASE_URL/LLM_API。
用户确认使用已有阿里云配置后，检测到 DASHSCOPE_API_KEY 与 DASHSCOPE_BASE_URL，
在测试进程内映射为 Reader 所用变量，使用 Chat Completions；没有编辑 .env 或系统变量。
现有地址属于百炼北京业务空间兼容端点，本页不记录完整业务空间标识。

依据[阿里云结构化输出文档](https://help.aliyun.com/zh/model-studio/qwen-structured-output)，
选择支持 JSON Schema 的 qwen3.7-plus 做首轮测试，每次最多4096输出token、自动重试为0。
首次一次真实摘要调用返回了合法 PaperAnalysis，原始输出保存在 abstract-smoke.json。
这证明当次请求成功，不证明服务持续可用或后续账号权限一致。

对这次输出逐字段检查：

| 字段 | 检查结果 |
| --- | --- |
| paper_title | 与输入一致 |
| problem / motivation | 空，属于保守输出；未将其当成完整提取覆盖 |
| method | Transformer及纯注意力描述有摘要依据；补入的encoder-decoder等细节不能从摘要明确归属于所提模型，不能直接通过 |
| datasets | WMT任务有摘要依据，但把English constituency parsing任务描述列为数据集，不符合字段语义 |
| metrics | BLEU有摘要依据 |
| main_results | 所列28.4/41.8 BLEU及3.5天/8 GPU等内容有摘要依据 |
| contributions | 与摘要提出模型和实验陈述相符；仍是作者陈述，不是独立验证 |
| limitations | 空，摘要未明确给出本方法局限，符合保守策略 |

据此收紧摘要提示：只接受具名数据集/语料/基准，不把任务/训练规模当数据集；不把
背景系统架构归给本文；不把普通注意力称作多模态融合。全文提示补充只提取本文结果，
排除相关工作/基线/参考文献的错误归属。修改效果尚未获得真实模型复测确认。

后续上限六次请求的测试批次实际尝试：两篇摘要、Attention第1/3/8页的三个全文片段，
以及一次错误诊断。两篇摘要回退为空，三个片段处理均失败、证据为0，协调器未被调用。
原计划明确仅分析第1/3/8页，不是整篇；本次失败更不能描述为完整全文验收。
失败后的 quote_offsets_valid=true 是空证据上的空集检查，**没有有效引句验证价值**。

脱敏诊断返回 HTTP403，code=`AccessDenied.Unpurchased`，
message=`Access to model denied. Please make sure you are eligible for using the model.`
随后只读模型列表可返回名称，但不代表已有调用权限；改用官方支持结构化输出的
qwen3.8-flash 只尝试一次，也返回相同403。之后停止生成请求，没有开通、购买或升级服务。
本轮共尝试8次生成请求：首次成功1次，其余7次失败；未获取服务商完整usage/账单，
本地预算准入计数不是实际token用量或费用，不能据此报告账单。

### 结果与人工核对

- 两篇摘要复测成功。Transformer数据集变为WMT 2014，不再把句法分析任务当数据集，
  也不再补入摘要未明确归属的encoder-decoder细节。BERT的基准与主要数值与摘要一致，
  未补入摘要未提到的MLM等细节。部分字段仍为空，不能称为提取覆盖完整。
- 第一次全文触发LengthFinishReasonError并回退；这是输出截断，不是余额错误。
  对该推理模型，不能假定2048/4096输出限额一定足够。后续两页显式配置8192输出、
  32768上下文预算，没有改变其他调用者的默认配置。
- 两页后续请求成功：14条候选通过当时的精确子串校验，全部原句偏移可回读；18条
  invalid_evidence被拒绝。没有保留这18条原始候选，不能证明全部只是空白差异。
- 保留证据中的层数、训练设置及来源数值可对应原文，但metrics中混入完整分数、
  训练时间和GPU吞吐信息，属于字段分类问题，不能因“引句存在”就判定提取合格。
- 真实协调成功返回method的compatible决定，保留6个可共存的方法/训练候选。没有
  触发main_results协调，因为模型把数值填入metrics。因此本轮未验证数值冲突判断。
- 原文第8页表格与正文一处数值不一致。本轮不裁决原文；最终main_results回退到摘要，
  field_sources为abstract，metrics仍保留不同数值。**整体全文质量仍不能通过**。

原始记录为临时目录中的abstracts-recharged.json、fulltext-recharged.json（截断失败）、
fulltext-recharged-8192.json及usage-prior-to-final.json（原usage归档快照），均被Git忽略。

### 无额外付费的修正

全文提示明确metrics仅填指标名称；带条件的数值放main_results、训练硬件/设置放method，
避免结果绕过字符串字段协调。提示修改尚未真实复测。
引句先精确匹配，再允许连续空白折叠为单个空格，保持词/数字边界，不删除全部空白，
不改变数字、大小写、标点、连字或连字符。evidence保存原文引句和原始偏移，
quote_match标记匹配方式。新增离线用例验证恢复以及不能拼接数字、单词或改变否定。
下一步只需小范围定向复测这些修正；本轮不再追加模型请求，不以离线测试替代真实效果。
